# Security

## Reporting a problem

Please don't report security problems in a public issue. Use GitHub's private reporting instead: on the [Security tab](https://github.com/unlimiteq/osutab/security), click **Report a vulnerability**. Only I can see the report.

Say what you found, which version of osu!tab it affects, and how to reproduce it if you can. I'll reply as soon as I can, and credit you in the changelog when it's fixed, unless you'd rather not be named.

## Supported versions

Only the latest release gets fixes.

## Worth knowing

osu!tab uses the tablet's USB debugging connection, which gives the connected PC deep access to the tablet. Only allow USB debugging from PCs you trust, and turn it off when you're not using osu!tab if that matters to you.
